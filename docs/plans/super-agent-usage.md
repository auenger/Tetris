# Super Agent 分支使用说明

当前开发分支：`feat/super-agent`。以下描述该分支源码能力，不代表已经发布。

## 开始

1. 安装并登录本机 Codex／Claude Code，打开一个工作目录。
2. 点击 Agent 面板按钮（macOS 快捷键 Option + Command + B）。
3. 可以直接选择执行器打开会话，也可以在“安排工作”中描述新工作、补充已有任务或要求停止。
4. 自动路由依赖本机 Codex；执行器可选择 Codex 或 Claude Code。

## 上下文

发送时读取最新画布选择，并包含所选对象的同组成员。没有选择时使用聚焦窗口／所属组，再回退当前目录的资源。面板中的“读取当前选择”可预览范围。传入的是引用索引，文件内容由执行器按需读取。

同一会话的消息属于同一任务。自然语言入口可以判断新建或跟进，归属不明确时返回澄清。运行中任务的补充要求会排队，停止任务会清理尚未处理的要求。

## 执行与检查

- 同目录任务串行，不同目录最多两项并行。
- 返回任务列表不结束后台会话。自动启动的任务可进入监视视图查看输出和授权请求。
- Claude 权限请求显示单次允许／拒绝入口；Codex 使用 workspace-write 的非交互执行模式，权限能力与 Claude 不完全相同。
- 可勾选完成后自动交给另一执行器检查，或在本轮完成后手动交接。
- 本轮结束进入待验收；“确认验收”由用户明确完成，不把模型结束直接视为业务完成。

## 产物与画布

执行报告持久化为 Markdown，可从任务卡片打开。报告是执行器的陈述，需要结合实际变更验收。打开报告时，会尝试加入原任务组；已有多个组不会自动合并。

派工和交付使用彩色 SVG 光线，运行期间显示虚线流动边框。目标不可见时跳过光线；减少动画设置关闭运动。光线源点在 Agent 面板边缘，不是嵌入 webview 内的具体聊天气泡。

## 独立 worktree

创建任务前可勾选独立 worktree。它从已提交状态创建专用分支，源仓库需干净。任务列表显示来源工作空间和执行分支。

“查看变更”展示 Git 状态与已跟踪文件 diff，未跟踪文件仅列在状态中。确认变更并提交后，可以快进集成到来源目录；分支已分叉时拒绝自动合并，请在终端处理。清理只接受已集成、干净、由 Tetris 管理的工作目录，并保留分支和历史记录。

## 当前验证边界

已通过关键模块定向测试、临时 Git 仓库的 worktree 创建/集成/清理、浏览器模拟界面与动效清理、生产构建。Codex 与 Claude 均完成了独立 Electron 的真实 IPC→创建文件→读回验证→任务记录→报告链路，磁盘内容由测试宿主再次核对。Claude 代理修复后的真实调用已通过。

自动 Codex→Claude 检查交接也已真实通过，检查器独立读取文件并保存报告。自然语言 Router 的真实请求出现 Codex 连接重试并超时，界面会明确提示任务尚未派发；网络恢复前可使用直接执行入口。完整主窗口的原生视觉交互目前被本机自动化服务不可用阻塞。测试使用临时仓库和画布夹具，不能代替实际主窗口点击与动效定位验收。

应用退出会停止受管理执行；记录保留，中断和排队工作不会在重启后自动重放。现有 PTY sidecar 存活能力不等于 Super Agent 能在 App 关闭后继续编排。
