# Super Agent 使用说明

开发分支：`feat/super-agent`。以下为本地测试版能力，未发布正式安装包。

## 开始

1. 打开工作目录，点击画布右上角 **Super Agent**。
2. 在底部选择优先执行器 Claude Code 或 Codex，直接描述目标。
3. 主管判断需要执行时，Tetris 创建独立任务和画布中的 Worker tile。主对话保留在右侧。
4. 点击消息里的任务卡，可定位执行 tile；tile 内展示工具调用、日志、授权请求、停止和报告入口。

主管 Runtime 使用本机 Claude Code（需已登录且网络可达），与 Worker 是不同进程和不同消息记录。主管自身禁用文件、终端及 MCP 工具，只能请求宿主创建任务、补充任务消息、查询任务状态和停止任务。实际执行仍使用 Claude ACP 或 Codex JSONL。

## 执行时继续对话

可以随时问“谁在做”“进度如何”，或者安排另一件事；Worker 的执行不会锁住主管输入框。主管自己处理消息时，新消息进入主管队列。

补充要求进入对应 Worker 的待处理队列，当前轮次结束后处理，不等于立即打断正在执行的命令。需要马上停止时，点击任务卡或 Worker tile 的停止按钮。停止会清理该 Worker 尚未处理的补充要求。

归属不明确时主管应澄清。任务完成会回传状态和报告，主管自动汇总；完成事件不会自行触发新任务。模型正常结束与人工验收分开记录。

## 上下文与任务范围

主管每轮获得工作目录、当前任务状态和画布引用索引。用户选择优先，并扩展同组 tiles；没有选择时使用聚焦对象／所属组，再回退目录内资源。输入框左下的加号可预览当前上下文。文件内容由 Worker 按需读取。

同目录任务串行，不同目录最多两项并行。可选择独立工作目录（Git worktree）；源仓库需干净，任务从已提交版本创建。在 Worker tile 中可查看 diff、快进集成已提交变更，以及清理已集成的干净目录。worktree 不构成系统级隔离。

## 画布与动效

派工创建受管理的 Agent 任务 tile，显示实际执行状态和结构化工具日志，并非向任意已有终端模拟键盘输入。关闭 tile 不结束任务，点击主管消息中的任务卡可以重新打开。

真实 running 事件触发派工流光，完成事件触发反向交付流光；运行期间有流动边框，等待授权时暂停边框。可见派工消息提供源锚点；消息不可见或尚未布局时回退到面板边缘。目标不可见时跳过，减少动画设置关闭运动。

任务 tile 与会话关联持久化；重开 App 可找回任务视图与历史。应用退出会停止受管理执行，中断或尚未确认的主管消息不会自动重放。

## 验证记录与边界

已通过真实 Electron IPC→主管 Runtime→Claude Worker→文件创建/读回→报告→主管汇总。验证中 Worker 运行时主管成功回答“谁在执行”，总任务数仍为 1，没有误派新任务；宿主读取文件内容为 `SUPERVISOR_OK\n`。

主管消息持久化、不重放、任务范围校验、事件不能派工等定向测试通过。浏览器模拟 UI 验证执行中发送可用；SVG 验证曲线随目标变换、反向交付、去重和清理。生产构建通过。主管链路的画布创建响应在独立 IPC 测试中使用夹具，不能等同于实际主窗口视觉验收；本机原生自动化服务仍不可用，请在测试 App 中确认任务 tile 和流光效果。

旧直接执行与 Codex 分类路由接口保留兼容；默认主入口现为独立主管，不再依赖旧的一次性 Codex Router。Codex Worker 的连接情况仍取决于本机 Codex 环境。
